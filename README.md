# Food-wastage-management

This is my  data visualization project using **Streamlit**, **MySQL**, and **Python**.

It shows food providers and receivers in different cities and visualizes the data using charts and tables.
This project aims to develop a Local Food Wastage Management System, where: Restaurants and individuals can list surplus food. NGOs or individuals in need can claim the food.
## 🔧 How to Run

1. Install Python if not already installed.

2. download the project files and have notebook(Anaconda) or visual studio to run the code.

3. Open a terminal and install required packages.#(pip install requiredpackage)
   
4. Need to install MYSQL and should connect with mysql.

Make sure your MySQL server is running and the database is connected.

## 📊 Features

- View number of food providers and receivers by city
- See total quantity of food donated
- Beautiful charts using Seaborn and Plotly
